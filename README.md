# EHR – Personal Health Record

A multilingual personal health record built as a static website (HTML, CSS and JavaScript only).

**Languages:** English · 繁體中文 · 简体中文 · 日本語 · 한국어 · Tiếng Việt

## Features

- Emergency summary at the top: blood type, allergies, current medications, emergency contact
- 22 sections in four groups:
  - **About me:** personal information, emergency contacts, doctors and clinics, insurance
  - **Medical history:** allergies, personal medical history, surgeries, hospital stays, family history, mental health, women's health
  - **Medications and tests:** current and past medications, vaccinations, vital signs, lab results, vision/dental/hearing, implants and devices
  - **Life and care:** lifestyle, travel history, care wishes, notes for doctors
- Edit mode to add, change and remove entries
- Your entries are translated automatically when you switch language. Translation runs on your device (Chrome or Edge on a computer), and the original text is shown under each translation. Fixed choices like sex, blood type, severity and status always switch language.
- Light and dark themes that follow your system setting
- Backup and restore by copying the data as JSON

## Usage

Open `index.html` in a browser, or publish it with GitHub Pages:
**Settings → Pages → Deploy from a branch → `Main` / root**.

## Privacy

Data is saved only in your browser's local storage. Nothing is sent to a server.
Do not commit real medical data to a public repository. Copy a backup after you edit.

# EHR – Hồ sơ sức khỏe cá nhân

Hồ sơ sức khỏe cá nhân đa ngôn ngữ, là một trang web tĩnh (chỉ dùng HTML, CSS và JavaScript).

**Ngôn ngữ:** Anh · Trung phồn thể · Trung giản thể · Nhật · Hàn · Việt

## Tính năng

- Tóm tắt khẩn cấp ở đầu trang: nhóm máu, dị ứng, thuốc đang dùng, người liên hệ khẩn cấp
- 22 mục chia thành 4 nhóm: Về tôi, Tiền sử bệnh, Thuốc và xét nghiệm, Cuộc sống và chăm sóc
- Chế độ chỉnh sửa để thêm, sửa và xóa thông tin
- Dữ liệu bạn nhập tự động được dịch khi đổi ngôn ngữ. Việc dịch chạy ngay trên máy (Chrome hoặc Edge máy tính), và bản gốc luôn hiện bên dưới bản dịch. Các lựa chọn cố định như giới tính, nhóm máu, mức độ, tình trạng luôn đổi theo ngôn ngữ.
- Giao diện sáng/tối theo cài đặt hệ thống
- Sao lưu và khôi phục bằng cách sao chép dữ liệu dạng JSON

## Cách dùng

Mở `index.html` bằng trình duyệt, hoặc đăng lên GitHub Pages:
**Settings → Pages → Deploy from a branch → `Main` / root**.

## Bảo mật

Dữ liệu chỉ được lưu trong trình duyệt của bạn, không gửi lên máy chủ nào.
Đừng commit dữ liệu y tế thật lên repo công khai. Hãy sao lưu sau mỗi lần chỉnh sửa.
